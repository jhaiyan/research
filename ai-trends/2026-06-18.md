### Loop Engineering（循环工程）🔥

- **定义**：一种系统化工程方法，通过精细化设计 Agent 执行循环中的状态管理、工具调用策略、上下文压缩和错误恢复机制，解决 Agent 长期运行过程中效率衰减与信息漂移的问题。
- **起源追溯**：LangChain 于 2026 年 6 月 16 日由 Sydney Runkle 在博客文章《The Art of Loop Engineering》中首次系统提出 [\[LangChain\]](https://www.langchain.com/blog/the-art-of-loop-engineering)。Martin Fowler 博客于同月 16 日刊发与拜耳合作的文章，提及了多步骤推理系统的可靠性挑战，侧面印证了这一工程需求的普遍性 [\[Martin Fowler\]](https://martinfowler.com/articles/building-reliable-agentic-ai-systems.html)。
- **提出背景**：随着 Agent 从单轮问答演进为多步骤、长时间运行的企业级应用（如拜耳的制药研究助手），Agent 在循环执行中出现效率衰减（每次迭代质量下降）和信息漂移（上下文在多轮后偏离原始目标）两大问题。传统 prompt 工程无法解决，催生了系统性的 Loop Engineering 方法论。
- **使用场景**：企业级多步骤研究助手、自动化代码生成管线、复杂文档分析与摘要、长周期任务自动化。
- **交叉验证**：LangChain 密集发布多篇相关工程文章（含 Fault Tolerance、Custom Agent Harness、Rubrics 自评体系等），形成完整生态；GitHub 上的 `headroom`（上下文压缩）和 `LMCache`（KV Cache 加速）项目也从基础设施层面呼应了这一需求。
- **争议与质疑**：目前未见显著争议，但工程复杂度较高，中小团队落地成本不容忽视。
- **相关链接**：

  - [Building Reliable Agentic AI Systems - Martin Fowler](https://martinfowler.com/articles/building-reliable-agentic-ai-systems.html)
  - [headroom - GitHub](https://github.com/mvanhorn/headroom)
  - [LMCache - GitHub](https://github.com/LMCache/LMCache)

### Skills 生态 🔥

- **定义**：以独立、可复用、可组合的"技能"（Skill）为基本单元构建 AI Agent 的开发范式。每个 Skill 完成特定子任务（如"搜索论文"、"操作 GitHub"），Agent 通过组合多个 Skill 完成复杂目标。
- **起源追溯**：`addyosmani/agent-skills` 项目由 Addy Osmani（Google Chrome 团队工程师）于 2026 年 6 月发布，周增 11,684 stars，总计 62,296 stars，迅速成为 GitHub Trending 第一名 [\[GitHub\]](https://github.com/addyosmani/agent-skills)。与此同时，`pm-skills`（周增 5,333 stars）、`last30days-skill`（月增 44k+ stars）、NVIDIA `SkillSpector`（AI Agent 安全扫描）等形成完整工具链。
- **提出背景**：随着 Agent 应用场景扩大，开发者需要一个标准化的技能封装格式来实现跨项目复用。Skills 相比传统"Tool"具备更丰富的元数据（描述、参数规范、依赖声明）和版本管理能力，成为比 Function Calling 更高层的抽象。
- **使用场景**：AI 编程助手、研究 Agent、产品管理自动化、多 Agent 协作系统。
- **交叉验证**：GitHub Trending 周榜和月榜双重验证（`pm-skills`、`agent-skills`、`phuryn/pm-skills` 均进入榜单），Skills 作为新范式已跨多个垂直领域（工程、产品、学术、网络安全）。
- **争议与质疑**：Skills 的标准化程度仍低，不同框架（LangChain、AutoGPT、CrewAI）的 Skill 格式互不兼容，存在碎片化风险。

### Agentic RAG 🌱

- **定义**：一种企业级检索增强生成架构，其检索模块具备自主决策能力——可判断是否需要外部知识、何时触发检索、如何对检索结果进行二次推理，而不仅是被动响应用户查询。
- **起源追溯**：Google Research 于 2026 年 6 月在博客文章《Unlocking Dependable Responses with Gemini Enterprise Agent Platforms: Agentic RAG》中系统阐述 [\[Google Research\]](https://research.google/blog/unlocking-dependable-responses-with-gemini-enterprise-agent-platforms-agentic-rag/)。该概念由 Google 企业级 Agent 平台团队提出，旨在解决传统 RAG 在企业知识管理中的局限性。
- **提出背景**：传统 RAG 的检索是静态的——用户提问后系统检索相关文档，Agent 无权决定是否检索以及检索策略。而企业级场景（如合规审查、财务分析）需要 Agent 根据上下文主动判断是否需要外部知识，并动态调整检索策略。
- **使用场景**：企业知识管理系统、合规审查自动化、财务报告分析、法律文档研究。
- **交叉验证**：LangChain Blog 在同期发布了多个 Agent RAG 相关工程文章（如 Box AI 案例），Agentic RAG 作为企业落地关键路径得到独立验证。
- **争议与质疑**：Agentic RAG 与传统 RAG 的边界仍有争议，部分观点认为其本质是"带判断能力的 RAG"而非全新范式。
- **相关链接**：
  - [Agentic RAG - Google Research](https://research.google/blog/unlocking-dependable-responses-with-gemini-enterprise-agent-platforms-agentic-rag/)
  - [Box AI with Deep Agents - LangChain](https://www.langchain.com/blog/building-box-ai-how-an-enterprise-content-platform-went-ai-native-with-deep-agents)

### World-Action Models（世界-动作模型）🌱

- **定义**：一种端到端统一感知、规划与控制的具身 AI 模型架构，通过预训练建立对物理世界的深度表征（世界模型），再通过微调适配特定动作任务，实现从"想象"到"执行"的直接映射。
- **起源追溯**：NVIDIA Developer Blog 于 2026 年 6 月 15 日发布文章《Pretrained to Imagine, Fine-Tuned to Act: The Rise of World-Action Models》首次系统提出 WAM 术语和全景架构解析 [\[NVIDIA\]](https://developer.nvidia.com/blog/pretrained-to-imagine-fine-tuned-to-act-the-rise-of-world-action-models/)。同期，Odyssey 获得 $3.1 亿融资（Amazon、NVIDIA、AMD）用于构建物理世界的 3D 模拟世界模型 [\[TechCrunch\]](https://techcrunch.com/2026/06/17/world-model-maker-odyssey-nabs-1-45b-valuation-backed-by-amazon-and-other-big-names/)。
- **提出背景**：具身智能长期受限于物理机器人数据采集成本高、场景泛化能力弱的问题。World-Action Models 通过在大规模视频/3D 数据上预训练世界模型，再结合少量机器人动作微调，实现低成本高泛化的端到端控制。
- **使用场景**：家庭服务机器人、工业制造自动化、自动驾驶、手术机器人。
- **交叉验证**：NVIDIA Cosmos 3 在 HuggingFace Papers 上获得 10,300 GitHub stars；阿里发布 Qwen-Robot 系列首个具身大模型（三连发）；量子位本周主题聚焦"世界模型能否抹平具身智能的数据鸿沟"。
- **争议与质疑**：World-Action Models 与传统 VLA（Vision-Language-Action）模型的边界不够清晰，部分学者认为其本质是 VLA 的扩展而非新范式。此外，高计算成本和部署挑战仍是落地障碍。
- **相关链接**：
  - [World-Action Models - NVIDIA](https://developer.nvidia.com/blog/pretrained-to-imagine-fine-tuned-to-act-the-rise-of-world-action-models/)
  - [Cosmos 3 - HuggingFace](https://huggingface.co/papers?query=cosmos+3)
  - [Odyssey $310M - TechCrunch](https://techcrunch.com/2026/06/17/world-model-maker-odyssey-nabs-1-45b-valuation-backed-by-amazon-and-other-big-names/)
