## Data Collection Requirements

For each model in your range, collect all of the following:

1. **Manufacturer** (制造商): Official native-language company name — Chinese companies in Chinese (e.g., `智谱`, `深度求索`, `月之暗面`, `阿里云`); Western companies in their official English name. Provide a verified markdown hyperlink to the manufacturer's official website.
2. **Model** (模型): Full model name with **exact, specific version number** (e.g., `GPT-4.5`, `Claude Sonnet 4.6`, `Gemini 2.5 Pro 05-06`). NEVER use a vague family name like `GPT-5` when a specific point-release or variant is publicly documented — search for the exact version before writing. Provide a verified markdown hyperlink to the model's own page (product page, API docs, or announcement post). If no model-specific page exists, omit the link.
3. **Scenario** (场景): All distinct deployment modes or access contexts for this model that carry **different technical specifications**. Each distinct scenario gets its own row in the table. Examples: `API`、`ChatGPT Web`、`Thinking (API)`、`Extended Thinking`、`Codex CLI`、`Azure OpenAI`、`Vertex AI`. Common scenario types to investigate:
   - **API access** (direct REST/SDK calls)
   - **Web interface** (consumer products, may have different context limits or feature sets)
   - **Thinking/Reasoning mode** (extended thinking variants with different token budgets and pricing)
   - **CLI / specialized tools** (purpose-built tools with different constraints)
   - **Third-party cloud deployments** (Azure, GCP Vertex, AWS Bedrock)
4. **Context Size** (上下文大小): Maximum context window. Human-readable format: `128K`, `1M`, `200K` — never raw numbers like `128000`.
5. **Max Input** (最大输入): Maximum input tokens. Same format.
6. **Max Output** (最大输出): Maximum output tokens. Same format.
7. **Reasoning** (推理能力): Raw integer score 0–10 based on complex reasoning benchmarks (ARC, HellaSwag, MMLU, GPQA, etc.).
8. **Math** (数学能力): Raw integer score 0–10 based on math benchmarks (GSM8K, MATH, AIME, etc.).
9. **Coding** (编程能力): Raw integer score 0–10 based on coding benchmarks (HumanEval, SWE-bench, LiveCodeBench, etc.).
10. **Vision** (视觉能力): Raw integer score 0–10 for multimodal/image understanding. Use `0` if not applicable.
11. **Instruction Following** (指令遵循): Raw integer score 0–10 for adherence to complex instructions.
12. **Hallucination Control** (幻觉控制): Raw integer score 0–10 for factual accuracy.
13. **Multilingual** (多语言): Raw integer score 0–10 for non-English language support quality.
14. **Long Context Effectiveness** (长上下文有效性): Raw integer score 0–10 for actual task performance in long contexts.
15. **JSON/Tool Call**: Raw integer score 0–10 for structured output and function calling reliability.
16. **Open Source** (开源): `✅` if open weights available; `❌` if closed. Categorical — NOT scored.
17. **Cost** (成本): Raw integer score 0–10 representing **relative API cost tier** where **`0 = cheapest`** and **`10 = most expensive`**. Synthesis applies inverse normalization so the cheapest item ends up at `10` and the most expensive at `0`.
18. **Overall** (综合评价): Raw integer composite score 0–10 reflecting overall capability.
19. **Use Cases** (适用场景): Short comma-separated Chinese labels.

> When you cannot find 3 sources for a scored field after a focused search, do **not** mark it `-` — perform 1 additional targeted search, then take the most credible source and flag the score as `[待验证]`. Only use `-` when the data is genuinely absent.

**Include ONLY models that satisfy ALL of the following:**
