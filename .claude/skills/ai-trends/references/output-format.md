## Format Notes

- **Link Requirements**: All sources in tables must contain complete URLs, format as `[Source Name](Complete URL)`
- **Chinese Quotes**: In Chinese context, use `"..."` instead of `"..."`
- **Bold Text**: When bolding Chinese text, keep spaces before and after `**` (otherwise renderer may not recognize)
  - Correct: `这是 **重要概念** 的说明`
  - Incorrect: `这是**重要概念**的说明`
- **Unverified Content**: Use `【未经核实】` prefix for claims without corroborating sources
- **Controversial Content**: Use `【有争议】` prefix for topics where credible sources disagree, clearly presenting multiple viewpoints
