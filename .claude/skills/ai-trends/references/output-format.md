# 输出格式模板

本模板定义简报的最终结构。所有内容必须来自 `evidence.jsonl`，每条数据都要有来源链接。

## 结构约束

1. 概念数量可以为 0；不为凑数降低证据标准。
2. 每个表格条目都要带来源链接；每条数字都要能回溯到证据对象。
3. 厂商自报数据标注“官方自报”，预印本标注“预印本”，形式化验证与学界认可必须分开表述。
4. 报告长度受 `budgets.json` 中的 `max_report_characters` 约束；超出时优先删减低价值条目，不删证据链。
5. 末尾必须有「研究覆盖与限制」一节，说明本次实际覆盖与未覆盖范围。

---

## 格式约定

- 链接格式为 `[来源名称](完整 URL)`，所有链接必须可访问且内容有效。
- 中文语境使用全角标点；数字不使用千分位。
- 加粗中文两侧保留空格，避免渲染异常。
- 未核实内容加 `【未经核实】`，存在分歧时加 `【有争议】` 并同时给出不同观点。
- 表格列宽不必对齐到渲染美观，但需通过 markdownlint 检查。
