## Skills 使用说明

### ai-trends

**功能与作用**: 对最新 AI 发展动态进行多源调研，输出结构化的 AI 前沿简报。

**触发条件**: 用户询问 AI 趋势、AI 动态、AI 简报或希望了解最新 AI 进展时。

```markdown
/ai-trends last 2 weeks
```

### deep-read

**功能与作用**: 对指定 URL 进行深度阅读、术语提取、事实核查与多维度分析，输出结构化的中文解读报告。

**触发条件**: 用户发送 URL 并要求深度解读、分析、翻译、验证内容时。

```markdown
/deep-read https://example.com/article
```

### deep-research

**功能与作用**: 对 IT 技术、软件工程概念、AI 术语、开发工具、框架、协议、方法论或技术产品进行多源交叉验证的深度调研，输出结构化的技术研究报告。

**触发条件**: 用户请求深度研究、技术调研、技术报告或希望深入理解某个技术概念时。

```markdown
/deep-research Kubernetes
```

### llm-coding-agents-comparison

**功能与作用**: 发现并对比当前最新的编程 LLM 与 AI 编码助手，基于多个权威来源交叉验证后输出综合比较报告。

**触发条件**: 用户请求 LLM 对比、编码助手对比、AI 编程工具对比或编程 LLM benchmark 时。

```markdown
/llm-coding-agents-comparison
```

### recommendation

**功能与作用**: 基于多源交叉验证，对高质量工具、服务或资源进行调研与排行，输出权威推荐列表。

**触发条件**: 用户询问“最好的”、top 推荐、推荐高质量工具或服务列表时。

```markdown
/recommendation 最好的 AI 编程助手
```

### update-readme

**功能与作用**: 扫描项目中的 Skills 与 git 追踪的 Markdown 报告，并更新 README.md 中的目录与 Skills 使用说明。

**触发条件**: Skills 被添加、删除、修改或生成新报告时。

```markdown
/update-readme
```
